# BirdRaise - 새 키우기 콘솔 게임

> C++로 제작한 Windows 콘솔 기반 새 육성 시뮬레이션 게임  
> 객체지향프로그래밍 수업 과제 | C++17

---

## 프로젝트 소개

길에서 발견한 작은 알 하나. 이름을 붙이고, 8주 동안 정성껏 돌보며 새가 성장하는 과정을 함께합니다.  
매주 주어진 행동 기회를 활용해 먹이를 주고, 청소하고, 훈련시키고, 놀아주세요.  
어떻게 키우느냐에 따라 다양한 엔딩이 펼쳐집니다.

---

## 주요 기능

- **성장 시스템** — 알 → 유아기 → 유년기 → 청소년기 → 성체, 총 5단계 성장
- **상태 관리** — 포만감 / 청결도 / 훈련도 / 스트레스 4가지 수치 실시간 관리
- **행동 선택** — 성장 단계마다 달라지는 행동 목록과 세부 선택지
- **아이템 & 인벤토리** — 훈련을 통해 아이템을 획득하고 선택지 해금
- **ASCII/Unicode 아트** — 성장 단계별 콘솔 아트 출력
- **다양한 엔딩** — 일반 엔딩 / 배드 엔딩 / 히든 엔딩

---

## 게임 진행 방식

1. 게임 시작 시 알에게 **이름**을 붙입니다.
2. 매주 **5번의 행동 기회**가 주어집니다.
3. 현재 **성장 단계**에 따라 가능한 행동 목록이 달라집니다.
4. 일부 행동은 **세부 선택지**를 한 번 더 선택합니다.
5. 선택한 행동에 따라 새의 **상태 수치**가 변화합니다.
6. **8주 경과** 또는 **사망/도주 조건** 발생 시 엔딩이 출력됩니다.

---

## 상태 수치 설명

| 수치 | 설명 | 위험 조건 |
|------|------|-----------|
| 포만감 | 새가 얼마나 배부른지 | 0이 되면 아사 엔딩 |
| 청결도 | 새와 주변 환경의 청결함 | 0이 되면 병사 엔딩 |
| 훈련도 | 얼마나 훈련되었는지 | — |
| 스트레스 | 새가 받는 스트레스 | 너무 높으면 도주 엔딩 |
| 만족도 | 위 4가지 수치 기반 종합 점수 | 엔딩 분기에 영향 |

---

## 성장 단계

| 주차 | 성장 단계 | 주요 행동 |
|------|----------|-----------|
| 1주차 | 알 | 품어주기, 쓰다듬어주기, 방치하기 |
| 2~3주차 | 유아기 | 이유식 먹이기, 청소하기, 놀아주기, 재우기 |
| 4~5주차 | 유년기 | 먹이 주기, 훈련 시키기, 청소하기 등 |
| 6~7주차 | 청소년기 | 전체 행동 가능, 훈련 강화 |
| 8주차 | 성체 | 모든 행동, 엔딩 분기 결정 |

> 먹이 주기는 일반 모이 / 견과류 / 해바라기씨 / 고급 모이 중 선택 가능  
> 일부 먹이는 훈련으로 획득한 아이템이 있어야 사용 가능

## 프로젝트 구조

```
BirdRaise/
├── src/
│   ├── Main.cpp           # 진입점, 콘솔 UTF-8 인코딩 설정
│   ├── GameManager.cpp    # 게임 전체 흐름 관리 (턴 진행, 행동 선택, 엔딩)
│   ├── GameEntity.cpp     # 새 객체 상태 관리 (수치, 성장 단계, 생존 여부)
│   ├── ActionManager.cpp  # 행동 목록, 세부 선택지, 아이템/인벤토리 처리
│   ├── Time.cpp           # 주차 및 행동 횟수 관리, 성장 단계 전환
│   └── UIRenderer.cpp     # 콘솔 화면 출력 (게이지, 아트, 엔딩)
└── include/
    ├── GameManager.h
    ├── GameEntity.h
    ├── ActionManager.h
    ├── Time.h
    └── UIRenderer.h
```

---

## 클래스 설계 (OOP)

| 클래스 | 역할 |
|--------|------|
| `GameManager` | 게임 루프 총괄, 각 매니저 클래스 조율 |
| `GameEntity` | 새 객체 — 상태 수치 캡슐화 및 관리 |
| `ActionManager` | 행동 정의 및 수치 변화 로직 |
| `Time` | 시간 흐름, 성장 단계 전환 조건 |
| `UIRenderer` | 출력 전담, 게임 로직과 UI 분리 |

## 빌드 및 실행

### 요구 환경
- OS: Windows
- Compiler: g++ (MinGW) 또는 Visual Studio
- Standard: C++17

### g++ 빌드

```bash
g++ -std=c++17 -Wall -Wextra -o BirdRaise.exe \
    src/Main.cpp src/GameManager.cpp src/GameEntity.cpp \
    src/ActionManager.cpp src/Time.cpp src/UIRenderer.cpp
```

### 실행

```bash
BirdRaise.exe
```

### Visual Studio 사용 시

1. 새 C++ 콘솔 프로젝트 생성
2. `src/`, `include/` 내 모든 파일을 프로젝트에 추가
3. 콘솔 출력 인코딩을 UTF-8로 설정
4. 빌드 후 실행

---

## 주의 사항

- 콘솔 폰트가 Unicode를 지원하지 않으면 아트가 깨질 수 있습니다.
- 실행 시 자동으로 `chcp 65001`을 호출하여 콘솔을 UTF-8로 전환합니다.
- **Windows 환경 전용**입니다 (Windows API 및 콘솔 함수 사용).
