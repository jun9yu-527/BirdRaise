BirdRaise - 새 키우기 콘솔 게임
================================

BirdRaise는 C++로 제작한 Windows 콘솔 기반 육성 시뮬레이션 게임입니다.
플레이어는 길에서 발견한 작은 알에게 이름을 붙이고, 8주 동안 돌보며 새가 성장하는 과정을 함께합니다.
매주 주어진 행동 횟수 안에서 먹이 주기, 청소하기, 훈련하기, 놀아주기 등의 선택을 하며,
포만감, 청결도, 훈련도, 스트레스 수치에 따라 다양한 엔딩을 볼 수 있습니다.


주요 기능
---------

- 8주 동안 진행되는 새 육성 시스템
- 알, 유아기, 유년기, 청소년기, 성체로 이어지는 성장 단계
- 성장 단계별 행동 선택지 제공
- 포만감, 청결도, 훈련도, 스트레스 기반 상태 관리
- 훈련을 통한 랜덤 아이템 획득
- 인벤토리 보유 여부에 따른 선택지 잠금/해금
- ASCII/Unicode 아트를 활용한 콘솔 화면 출력
- 플레이 결과에 따른 일반 엔딩, 배드 엔딩, 히든 엔딩 제공


게임 진행 방식
--------------

1. 게임을 시작하면 알에게 이름을 붙입니다.
2. 한 주마다 5번의 행동 기회가 주어집니다.
3. 현재 성장 단계에 따라 가능한 행동 목록이 달라집니다.
4. 일부 행동은 세부 행동을 한 번 더 선택합니다.
5. 선택한 행동에 따라 새의 상태 수치가 변화합니다.
6. 8주가 지나거나 특정 사망/도주 조건이 발생하면 엔딩이 출력됩니다.


상태 수치
---------

- 포만감: 새가 얼마나 배부른지 나타냅니다.
- 청결도: 새와 주변 환경의 깨끗함을 나타냅니다.
- 훈련도: 새가 얼마나 훈련되었는지 나타냅니다.
- 스트레스: 새가 받는 스트레스 정도를 나타냅니다.
- 만족도: 포만감, 청결도, 훈련도, 스트레스를 바탕으로 계산되는 종합 수치입니다.

포만감이나 청결도가 0이 되면 사망 엔딩으로 이어질 수 있고,
스트레스가 너무 높으면 도주 엔딩으로 이어질 수 있습니다.


성장 단계
---------

- 1주차: 알
- 2~3주차: 유아기
- 4~5주차: 유년기
- 6~7주차: 청소년기
- 8주차: 성체


주요 행동
---------

알 단계:
- 품어주기
- 쓰다듬어주기
- 방치하기

유아기 이후:
- 이유식 먹이기
- 먹이 주기
- 청소하기
- 훈련 시키기
- 놀아주기
- 재우기

일부 행동은 세부 선택지를 가집니다.
예를 들어 먹이 주기는 일반 모이, 견과류, 해바라기씨, 고급 모이 중 하나를 선택할 수 있습니다.
단, 일부 먹이는 훈련을 통해 아이템으로 획득해야 사용할 수 있습니다.


프로젝트 구조
-------------

Main.cpp
- 프로그램 진입점입니다.
- 콘솔 인코딩을 UTF-8로 설정하고 GameManager를 실행합니다.

GameManager.h / GameManager.cpp
- 게임 전체 흐름을 관리합니다.
- 시작 스토리, 턴 진행, 행동 선택, 결과 반영, 엔딩 출력을 담당합니다.

GameEntity.h / GameEntity.cpp
- 새 객체의 상태를 관리합니다.
- 이름, 성장 단계, 포만감, 청결도, 훈련도, 스트레스, 생존 여부 등을 저장합니다.

ActionManager.h / ActionManager.cpp
- 성장 단계별 행동 목록과 세부 선택지를 관리합니다.
- 행동별 상태 변화량, 아이템 획득, 인벤토리 필터링을 처리합니다.

Time.h / Time.cpp
- 주차와 행동 횟수 등 시간 흐름을 관리합니다.
- 주 종료, 성장 단계 변경, 게임 종료 조건 평가를 담당합니다.

UIRenderer.h / UIRenderer.cpp
- 콘솔 화면 출력을 담당합니다.
- 상태 게이지, ASCII/Unicode 아트, 행동 결과, 엔딩 아트를 출력합니다.


빌드 및 실행 방법
-----------------

이 프로젝트는 Windows 콘솔 환경을 기준으로 작성되었습니다.
UTF-8 출력과 Windows API 사용을 위해 Windows 환경에서 실행하는 것을 권장합니다.

g++ 사용 예시:

    g++ -std=c++17 -Wall -Wextra -o BirdRaise.exe Main.cpp GameManager.cpp GameEntity.cpp ActionManager.cpp Time.cpp UIRenderer.cpp

실행:

    BirdRaise.exe

Visual Studio를 사용하는 경우:

1. 새 C++ 콘솔 프로젝트를 생성합니다.
2. 모든 .cpp, .h 파일을 프로젝트에 추가합니다.
3. 문자 집합과 콘솔 출력이 UTF-8로 표시되도록 터미널 환경을 설정합니다.
4. 빌드 후 실행합니다.


개발 환경
---------

- Language: C++
- Standard: C++17
- Platform: Windows Console
- Encoding: UTF-8


주의 사항
---------

- 콘솔 폰트가 Unicode 문자를 지원하지 않으면 아트가 깨져 보일 수 있습니다.
- 실행 시 Main.cpp에서 chcp 65001을 호출해 콘솔 코드 페이지를 UTF-8로 변경합니다.
- 일부 콘솔 환경에서는 한글 또는 특수문자 출력이 다르게 보일 수 있습니다.
